# Ritmo

Rotina diária com dashboard, modo foco (ciclos de 50 min), hábitos e tarefas. Site estático em um único `index.html`; os dados ficam salvos no navegador (localStorage).

Acesse: https://vitorodrix.github.io/ritmo/

## Instalar como app no Mac

- **Safari** (macOS Sonoma ou mais novo): abra o site e vá em *Arquivo → Adicionar ao Dock*.
- **Chrome**: abra o site e clique no ícone de instalar na barra de endereço (ou *⋮ → Transmitir, salvar e compartilhar → Instalar página como app*).

O app abre em janela própria, aparece no Launchpad e funciona sem internet.
